# Product Roadmap

## Complete through Phase 2

- venture-first Founder foundation and canonical project routing;
- compact shared workspace visual system;
- Founder Home continuity;
- source provenance and review;
- confirmed venture baseline;
- deterministic Challenge Scan;
- critical-decision selection and Explore;
- falsifiable experiment planning;
- evidence requirements and lightweight tasks;
- action-cycle commit/start;
- Overview, Home, Projects, persistence, and focused-test integration.
- role-neutral venture core contracts and a layered Decision Loop
  capability with application services, repository port, deterministic
  mock adapter, and focused characterization/integration coverage.

## Phase 3 — Evidence and Learning

- evidence submission and source attachment;
- evidence review and accept/reject states;
- reviewer feedback reconciliation;
- outcome and learning capture;
- repeat, pivot, pause, and complete decisions;
- evidence-backed readiness deltas with explanations;
- notifications only where the workflow requires them.

Phase 3 must consume Phase 2 decision, experiment, evidence-requirement, task, and cycle identifiers rather than introducing parallel state.

Phase 3 persistence should implement the existing Decision Loop
repository port (or an intentionally versioned successor) rather than
moving transport concerns into presentation. Authorization and
multi-user collaboration may replace the current Founder demo
composition root without changing domain invariants or route-level
screen contracts.

## Later phases

- Program Mode and deliverable workflows;
- opportunity and specialist matching;
- production persistence and authorization;
- real file/email/calendar/AI integrations;
- Mentor and Investor workflow alignment;
- analytics and operational reporting.

No later phase should re-center generic content generation, pitch polish, or marketplace browsing ahead of the venture decision loop.
